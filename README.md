# Voter Search

A static, searchable copy of the Bangalore Teachers' Constituency electoral roll.
Search by name (any word order, initials optional) or EPIC number; filter by constituency.

- `index.html`: the search page (no server or build step needed)
- `data.js`: the voter data, generated by `build_site.py` from `Electoral_Roll_Extracted.xlsx`

## Publish on GitHub Pages

1. Create a new repository on GitHub and upload `index.html`, `data.js` and this README
   (or push this folder with git).
2. In the repository: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   branch `main`, folder `/ (root)`, then **Save**.
3. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Updating the data

Re-run `python build_site.py` in the `finalList` folder, then commit and push the new `data.js`.
